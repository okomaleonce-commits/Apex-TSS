# preuves/ — preuves par jalon et par piste

Chaque jalon (G0→G6) ne se franchit que sur **sa preuve**, déposée ici. Convention
de nommage : `G<n>_<domaine>_<piste>.md` (ex. `G1_marche_entretien_manuel.md`,
`G2_import_rangement_voyage.md`). Les VETO : `VETO_G<n>_<piste>.md`.

Ce dossier est **vide au départ** : aucune piste n'a encore de preuve. Voir
`docs/02_JALONS.md` pour la preuve attendue à chaque jalon.
